We take the security of our users and systems seriously. If you believe you’ve found a vulnerability, please follow the guidance below to report it responsibly.

## Account and Device Compromise Response

Use this checklist when phone, email, OpenAI/ChatGPT, Apple ID, or carrier compromise is suspected:

- Preserve evidence first: dates, screenshots, carrier messages, email headers, device alerts, and account login history.
- Rotate passwords from a trusted device, starting with Apple ID, email accounts, password manager, phone carrier, OpenAI, banking, and domain registrar accounts.
- Enable phishing-resistant MFA where available. Remove unknown trusted devices, recovery emails, forwarding rules, app passwords, OAuth grants, and API keys.
- Ask each carrier/VoIP provider for a port freeze, account PIN, SIM swap lock, call-forwarding review, device list review, and fraud case number.
- Confirm email sync by checking aliases, forwarding, filters, recovery contacts, DKIM/SPF/DMARC, mailbox rules, and connected mail clients.
- Update devices, inspect configuration profiles and MDM, remove unknown VPNs, reset network settings, and use Lockdown Mode if there is credible targeted spyware risk.
- If compromise remains credible after account recovery, back up critical files, erase and restore devices from trusted media, then re-add accounts one at a time.
